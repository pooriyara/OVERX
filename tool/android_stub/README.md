# استاب‌های کامپایل برای لایه‌ی اندروید

هدف: بتوان کاتلینِ `android/app/src/main/kotlin` را **واقعاً** کامپایل کرد،
بی‌آنکه `libbox.aar` یا یک اندروید SDK کامل داشته باشیم.

```
tool/android_stub/         کلاس‌های تولیدشده‌ی ساخت (R) و یادداشت‌های androidx
tool/libbox_stub/          همان چیزی که gobind از سورسِ Go تولید می‌کند
```

هیچ‌کدام وارد APK نمی‌شوند: بیرون از پوشه‌ی `android/` اند و گریدل آن‌ها را
نمی‌بیند. اجرا:

```bash
./tool/check_android.sh
```

خروجیِ مطلوب: `تعداد خطاها: ۰`.
